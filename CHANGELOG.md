# Changelog

All notable changes to this project will be documented in this file.

## [1.1.1-beta] - 2026-03-17
### Added
- Animated header logo + rainbow/watercolor title animation.
- UI theming system with built-in themes and theme import/export.

### Changed
- Merged upstream `1.1.0` changes.
- Updated README to focus on fork vs upstream differences.

### Fixed
- Various UI/UX fixes from upstream merge.

## [1.0.7] - 2026-03-15
### Added
- Prevent crashes and improve responsiveness across UI and background services.

### Changed
- Optimized animation sampling and audio processing.
- Improved transition handling and background activity management.
- Enabled release build minification and resource shrinking.

### Fixed
- Various stability improvements and edge-case handling.

## [1.0.6] - 2026-03-14
### Added
- New **CPU temperature** LED animation (color reacts to thermal readings).

### Changed
- Minor improvements and stability enhancements.

### Fixed
- Various small fixes.

## [1.0.5] - 2026-03-13
### Added
- Auto-start option to launch Bifrost on device boot.
- New LED charging indicator behavior: breathing while charging, charging speed indicator, and flash when fully charged.

### Changed
- Updated UI layout and animation responsiveness across the app.
- Improved animation smoothing and LED transition behavior.
- Updated versioning and release metadata.

### Fixed
- Various stability and UX improvements.

## [1.0.4] - 2026-03-12
### Changed
- Bumped version to 1.0.4.
- Minor internal cleanup and dependency updates.
